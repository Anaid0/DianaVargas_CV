# Portafolio Estático - Diana María Vargas Pedraza

Este es el sitio web estático del portafolio, listo para subir a Netlify.

## Estructura de archivos

```
static-site/
├── index.html      # Página principal
├── styles.css      # Estilos CSS
├── script.js       # Funcionalidad JavaScript
├── images/         # Imágenes del portafolio
└── README.md       # Este archivo
```

## Cómo subir a Netlify

1. Ve a [Netlify](https://www.netlify.com/)
2. Arrastra la carpeta `static-site` completa a la zona de drop de Netlify
3. ¡Listo! Netlify te dará una URL para compartir tu portafolio

## Notas

- Asegúrate de que todas las imágenes estén en la carpeta `images/`
- El sitio es completamente estático y no requiere servidor
- Todas las funcionalidades interactivas están implementadas en JavaScript puro
